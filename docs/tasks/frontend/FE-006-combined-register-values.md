## Implementation handoff (2026-10-18)

- Pure `lib/combined.ts` and `combined-copy.ts` decode one complete snapshot, keep integers as BigInt, apply the documented four orders, and format exact integer/IEEE values. Grouping rejects snapshots with mismatched quantity and preserves trailing raw words.
- Shared PollSetup adds Interpretation draft controls and acknowledged Apply, with errors retained on rejection. UI handoff carries draft settings/errors and inspector address, never sampled BigInts. CombinedGrid provides grouped address ranges, raw-word inspection, raw-expanded copy and column resizing in both hosts. Existing 16-bit grid remains the rendering path for the original modes.
- Combined mode disables scale providers/editors and leaves saved scales/columns intact. Write prefill uses the first original word and a 16-bit format, with the raw-write explanation.
