## 4. Failures (identical 3/3)
1. **CHK2-E12 "frame 639 stays a popover when the sub-window becomes inactive" (frontend).** Two sub-windows, A at width 639, A's setup open (popover, correct); activate B: A's popover disappears and a 300 px dock appears. Measured at 100% scale: the inactive frame border is computed `1px` (design says 1.5 px, Chromium floors it), so a frame of 639 has a PollView of 637 and the code adds `frameInset` 3 -> 640 -> dock. Active: 639 -> PollView 635 -> popover (OK); 640 -> 636 -> dock (OK). Inactive 640, 641, 900 stay dock and 600 stays popover; only 639 is wrong. Suggestion: take the frame width from the frame itself (offsetWidth / layout rectangle) instead of body + constant. Not measured at 125/150%.
2. **CHK2-G6 "the text does not change while S6 is open" (frontend; DES-002 2.11).** Connect, poll 1 Polling, press the close button (S6 shows "A kept poll keeps polling in the background."), then `setPollActive(1, false)` in the fake: the sentence vanishes from the open dialog. Expected: read when the dialog opens and kept. The G6 table itself passes (9 rows in the sub-window, plus Polling and Paused in a native window).
3. **CHK2-E17 extra check "counters complete" at frame 600, Timeout case (design step width + frontend).** Item E17 itself passes. In the Timeout case the counters need 308 px and get 300.1 px (cut by 8 px; the end of `SR 100 ms` is ellipsized); the Polling case fits (307.5 of 308).
4. **CHK2-E19 frame 430 (status line 426), 4-digit Tx (design step width + frontend).** Counters need 202.5 px and get 180.4 px (Polling, cut by 23 px) and 173 px (Timeout, cut by 30 px), ending with "…". The other E19 checks pass (Show is `columns-3` + chevron with accessible name and tooltip "Show Raw", same menu, no clipping; boundary 484 shows text, 483 icon only; Tx 1000000 + `(effective 180 ms)` is cut with an ellipsis and the tooltip carries the complete text).
